# Superpowers

Chat with your notes and give Obsidian new abilities. Describe what you need in everyday language, and Superpowers can help you organize your vault or create a custom plugin for you.

Designed for desktop and mobile, with your choice of OpenAI, Claude, or Gemini.

## What can you do?

- **Work with your notes.** Ask questions, find information, and ask Superpowers to create or update notes for you.
- **Create tools that fit your life.** Describe a workout tracker, a reading log, or another tool you wish you had, and ask Superpowers to build it.
- **Improve things through conversation.** Try the result, explain what you would like to change, and let Superpowers update it.

For example:

> “Create a workout tracker where I can record exercises, sets, and weights, and review my progress.”

> “Add a button to repeat my last workout.”

## How it works

Open the chat and explain what you want. Superpowers can work with your notes, create new features, and activate the plugins it builds. You can keep refining the result in the same conversation.

An activity indicator shows what it is doing. Expand it to see the steps, or stop the response whenever you need to. Your conversation is saved so you can return to it later.

The plugins it creates work independently: you can keep using them even if you turn off Superpowers.

## Get started

1. Install Superpowers. To try the beta, install **BRAT** from Community plugins, choose **Add a beta plugin for testing**, and enter `https://github.com/cilvet/obsidian-superpowers`.
2. In Superpowers settings, choose your AI provider and add your own API key.
3. Open Superpowers from the sidebar icon or the command palette and describe what you need.

You can type your requests or use voice dictation. The built-in dictation feature requires an OpenAI API key; your device’s keyboard dictation is another option.

On each device, add your API key separately. If you use Obsidian Sync Standard, install and update Superpowers with BRAT on each device, as the plugin exceeds that plan’s file size limit.

## Your data and AI provider

Superpowers connects directly to the provider you choose. There is no Superpowers server or tracking. Your messages and any notes the assistant uses are sent to that provider to answer your request. Built-in dictation sends your audio to OpenAI.

API keys stay on your device and are not shared through Obsidian Sync. You need an API account with your chosen provider, and usage may incur charges from them.

Superpowers can make changes to your vault and activate the plugins you ask it to create. Review the results as you go.
